# Velvet Vogue - Online Fashion Store

Velvet Vogue is a modern e-commerce platform specializing in trendy fashion apparel including t-shirts, hoodies, pants, and shorts.

## Features

- 👕 Product Categories: Browse through various clothing categories
  - T-shirts
  - Hoodies
  - Pants
  - Shorts
- 🛒 Shopping Cart: Add, update, and remove items
- 👤 User Authentication: Secure login and registration system
- 💳 Payment Processing: Secure checkout process
- 📱 Responsive Design: Optimized for both desktop and mobile devices
- 👤 User Profiles: Personalized user accounts
- 📞 Contact & Support: Inquiry form and customer support

## Tech Stack

- PHP
- MySQL
- HTML/CSS
- XAMPP (Apache Server)

## Installation

1. Install XAMPP on your system
2. Clone this repository to your `htdocs` folder:
3. Start Apache and MySQL services in XAMPP
4. Import the database:
   - Open phpMyAdmin
   - Create a new database named `velvet_vogue`
   - Import the database schema (if provided)
